# 💰 Sistema de Gestão Financeira

Sistema de gestão financeira desenvolvido em Python como projeto de estudo e portfólio para o curso de Análise e Desenvolvimento de Sistemas (ADS).

## 📊 Sobre o projeto

O sistema foi desenvolvido para auxiliar no controle financeiro de uma empresa, permitindo organizar informações de entradas, saídas e movimentações financeiras.

## 🚀 Funcionalidades

- 💵 Cadastro e controle de entradas
- 💸 Cadastro e controle de saídas
- 📅 Controle de contas a pagar
- 💰 Controle de contas a receber
- 📊 Relatórios financeiros
- 📈 Visualização das movimentações
- 🗂️ Organização das informações financeiras

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter
- Programação Orientada a Objetos
- Git
- GitHub
